# Changelog

## 1.0.0 — 2026-11-04

- Primeira versão MVP local: painel administrativo, perfis por formulário, Elementor Pro Action, formulário nativo (bloco + shortcode).
- Payload de entrada `core-webhook-v2`, validação, allowlist HTTPS e minimização de dados.
- Outbox limitada com retries idempotentes, métricas redigidas e limpeza/privacidade.
- Testes de contrato com HTTP mockado e documentação de riscos/rollback.
- **Não foi feita homologação real em WordPress/Elementor nem conexão ao CRM.**
